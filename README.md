# 🏫 نظام إدارة المدرسة المتكامل — دليل التثبيت والتشغيل الشامل

نظام متكامل، عصري، وخفيف لإدارة المدارس والمؤسسات التعليمية بالكامل باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL). يعمل على أي استضافة مشتركة تدعم PHP و MySQL (مثل cPanel، Namecheap، Hostinger، وغيرها) أو على الخوادم المحلية (AppServ، XAMPP، WampServer) دون الحاجة لأي أدوات بناء أو Node.js أو مكتبات خارجية.

---

## 📁 محتويات حزمة النظام

| الملف | الوصف والدور |
| :--- | :--- |
| `index.html` | الواجهة الأمامية الكاملة بنظام تطبيق الصفحة الواحدة (SPA) بتصميم متجاوب بالكامل وتنقّل سلس عبر الـ Hash. |
| `api.php` | الواجهة الخلفية الكاملة (Backend API) تدعم PDO، القفل التفاؤلي (Optimistic Locking)، والحماية المتقدمة. |
| `config.php` | ملف الإعدادات الأساسي للاتصال بقاعدة البيانات وتعيين المفاتيح الأمنية. |
| `database.sql` | هيكل قاعدة البيانات للإنشاء اليدوي (مع العلم أن النظام ينشئ الجداول تلقائياً عند أول تشغيل). |
| `.htaccess` | حماية الملفات الحساسة، ترويسات الأمان المتقدمة، وضبط التخزين المؤقت (Cache-Control). |
| `sw.js` | عامل الخدمة (Service Worker) لدعم تثبيت الموقع كتطبيق هاتف (PWA) والعمل دون اتصال. |
| `manifest.webmanifest` | بيانات تعريف تطبيق الويب التقدمي (PWA Manifest) باللغة العربية. |
| `icon-192.png` & `icon-512.png` | أيقونات التطبيق بجودة عالية لتثبيته على شاشة الهاتف الرئيسية. |

## 🚀 أولاً: خطوات الرفع على الاستضافة (cPanel / Namecheap)

1. **تسجيل الدخول إلى لوحة التحكم (cPanel):**
   - افتح لوحة التحكم الخاصة باستضافتك وانتقل إلى **مدير الملفات (File Manager)**.
   - ادخل إلى المجلد الرئيسي للموقع، وهو غالباً `public_html` (أو المجلد الفرعي مثل `public_html/school`).

2. **رفع الملفات:**
   - قم برفع ملفات النظام كاملة داخل المجلد.
   - تأكد من وجود ملف `.htaccess` (قد تحتاج إلى تفعيل خيار "Show Hidden Files / إظهار الملفات المخفية" من إعدادات File Manager لرؤيته).

## 🗄️ ثانياً: إنشاء قاعدة البيانات وضبط الاتصال

1. **إنشاء قاعدة البيانات في cPanel:**
   - من لوحة cPanel، انتقل إلى **قواعد بيانات MySQL (MySQL Databases)**.
   - أنشئ قاعدة بيانات جديدة، مثلاً: `username_school`.
   - أنشئ مستخدم MySQL جديد بكلمة مرور قوية، مثلاً: `username_dbuser`.
   - أضف المستخدم إلى قاعدة البيانات مع منحه **كافة الصلاحيات (ALL PRIVILEGES)**.

2. **ضبط ملف `config.php`:**
   - افتح ملف `config.php` باستخدام محرر الأكواد في الاستضافة وعدّل القيم التالية:
   ```php
   define('DB_DRIVER', 'mysql');       // نوع المحرك: mysql
   define('DB_HOST', 'localhost');     // خادم قاعدة البيانات (غالباً localhost)
   define('DB_PORT', 3306);            // المنفذ
   define('DB_NAME', 'اسم_قاعدة_البيانات'); 
   define('DB_USER', 'اسم_مستخدم_القاعدة'); 
   define('DB_PASS', 'كلمة_مرور_القاعدة'); 
   define('DB_PREFIX', 'sc_');        // بادئة الجداول
   define('INITIAL_USER', 'admin');    // اسم مستخدم المدير الأولي
   define('INITIAL_PASS', 'admin123'); // كلمة مرور قوية للمدير (>= 6 أحرف)
   define('DEBUG_SETUP', false);       // اجعلها false في بيئة الإنتاج
   ```

3. **إنشاء الجداول:**
   - **تلقائياً:** بمجرد فتحك لرابط الموقع في المتصفح، سيقوم ملف `api.php` بفحص قاعدة البيانات وإنشاء كافة الجداول الـ 13 تلقائياً دون أي تدخل منك!
   - **أو يدوياً (اختياري):** يمكنك الدخول إلى **phpMyAdmin**، واختيار قاعدة البيانات، ثم الضغط على **Import (استيراد)** واختيار ملف `database.sql`.

## 🔑 ثالثاً: أول دخول للنظام (حساب المدير العام)

1. افتح رابط موقعك في المتصفح، مثلاً: `https://your-domain.com/`.
2. اضغط على زر **«تسجيل الدخول»** في أعلى الصفحة، واختر تبويب **«معلم / إدارة»**.
3. أدخل البيانات الافتراضية:
   - **اسم المستخدم:** `admin` (أو القيمة المحددة في `INITIAL_USER`).
   - **كلمة المرور:** `admin123` (أو القيمة المحددة في `INITIAL_PASS`).
4. **تنبيه أمني:**
   - إذا كانت كلمة المرور المحددة أقل من 6 أحرف أو كلمة افتراضية مثل `1234`، سيظهر لك النظام شريط تنبيه أحمر دائم يطالبك بتغييرها فوراً من صفحة **«إعدادات النظام»**.

## 🔒 رابعاً: تفعيل اتصال HTTPS الآمن

لحماية بيانات الطلاب وتشفير الجلسات عبر طبقة SSL:
1. تأكد من تفعيل شهادة SSL لموقعك (شهادة مجانية مثل Let's Encrypt متوفرة في معظم الاستضافات).
2. افتح ملف `.htaccess` وابحث عن السطور التالية في نهاية الملف:
   ```apache
   # <IfModule mod_rewrite.c>
   #     RewriteEngine On
   #     RewriteCond %{HTTPS} off
   #     RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
   # </IfModule>
   ```
3. قم بإزالة علامة التعليق `#` من بداية الأسطر الأربعة لتصبح:
   ```apache
   <IfModule mod_rewrite.c>
       RewriteEngine On
       RewriteCond %{HTTPS} off
       RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
   </IfModule>
   ```
4. احفظ الملف، وسيتم تحويل جميع الزوار تلقائياً إلى الرابط المشفر `https://`.

## ⏰ خامساً: ضبط النسخ الاحتياطي التلقائي ومهام Cron (اختياري)

- **النسخ مع حركة الموقع (دون Cron):** النظام مزوّد بمحرك ذكي يفحص تلقائياً عند كل حفظ أو استعلام موعد النسخ الاحتياطي المحدد (كل 12 ساعة، يومياً، كل يومين، أسبوعياً)، ويأخذ نسخة احتياطية مشفرة ومضغوطة تلقائياً في جدول `sc_snaps` إذا طرأ أي تغيير على بصمة البيانات (SHA-1).
- **النسخ عبر مهمة Cron المجدولة (اختياري إضافي):**
  - من لوحة cPanel، اذهب إلى **Cron Jobs (المهام المجدولة)**.
  - اضبط التكرار على "مرة يومياً" عند منتصف الليل.
  - ضع الأمر التالي (مع استبدال رابط موقعك ومفتاح CRON_KEY المحدد في `config.php`):
    ```bash
    curl -s "https://your-domain.com/api.php?a=cron&key=Sch00l_Cr0n_S3cur3_K3y_2026" > /dev/null
    ```

## 📋 سادساً: قائمة الاختبار اليدوي السريع للتأكد من عمل كافة الميزات

| # | الميزة المراد اختبارها | الإجراء والنتيجة المتوقعة |
| :-: | :--- | :--- |
| 1 | **الصفحة العامة للزوار** | افتح الموقع دون تسجيل دخول. تأكد من ظهور شريط الهيدر، البطاقات الإحصائية، نبذة المدرسة، والمميزات. |
| 2 | **تسجيل دخول المدير** | سجّل دخولك بحساب `admin` وتأكد من الانتقال إلى لوحة المعلومات وظهور الشريط الجانبي. |
| 3 | **البحث السريع (Ctrl+K)** | اضغط `Ctrl+K` واكتب اسم أي طالب أو اسم صفحة؛ يجب أن تظهر النتائج فوراً مع إمكانية الانتقال لها. |
| 4 | **إضافة واستيراد الطلاب** | ادخل صفحة **«إدارة الطلاب»**، أضف طالباً جديداً، أو الصق سطوراً من Excel وتأكد من ظهور الطلاب في الجدول. |
| 5 | **فحص وتدقيق البيانات** | اضغط على زر **«فحص وتدقيق البيانات»** للتأكد من كشف الطلاب بدون هواتف أو بدون صفوف أو الهويات المكررة. |
| 6 | **حسابات أولياء الأمور** | ادخل **«حسابات أولياء الأمور»**، واضغط **«فتح حسابات لكل من ليس له حساب»**؛ يجب توليد كلمات المرور وتوفير خيار تصديرها. |
| 7 | **تسجيل الحضور اليومي** | ادخل صفحة **«الحضور والغياب»**، سجّل غياب أحد الطلاب، واضغط زر **«مراسلة ولي الأمر»** لتوليد رابط WhatsApp الجاهز. |
| 8 | **سجل العلامات وإدخال الأسهم** | ادخل **«سجل العلامات»**، اختر شعبة ومادة، واستخدم الأسهم للتنقل بين خلايا الاختبارات والنهائي وتأكد من الحساب التلقائي. |
| 9 | **الشهادات المدرسية والمعاينة الحية** | ادخل صفحة **«الشهادات»**، بدّل بين القوالب الـ 6، وتأكد من تغير المعاينة المباشرة فورياً وظهور الختم وتنسيق الطباعة. |
| 10 | **بوابة الطالب** | سجّل خروجك وسجّل الدخول بحساب طالب (رقم الطالب وكلمة المرور). تأكد من ظهور بطاقته، حلقة التقييم، علاماته، وحجب البيانات الحساسة. |
| 11 | **بوابة ولي الأمر والتبديل بين الأبناء** | سجّل دخول برقم هاتف مسجل لأكثر من طالب (مثل `0599123456`)؛ تأكد من ظهور شريط الأبناء والتبديل السلس بينهم بضغطة زر. |
| 12 | **قائمة فحص الأمان** | ادخل بحساب المدير إلى **«الأمان والتدقيق»** وتأكد من ظهور البنود الـ 8 بعلامات ✓ الخضراء. |
| 13 | **النسخ الاحتياطي اليدوي** | من صفحة **«الإعدادات»**، اضغط **«أخذ نسخة احتياطية الآن»** ثم قم بتنزيل ملف JSON للتأكد من سلامة الأرشيف. |
| 14 | **الوضع الليلي والـ PWA** | اضغط على أيقونة القمر 🌙 لتبديل المظهر الداكن، وتأكد من ظهور زر "تثبيت التطبيق" على الهاتف. |
